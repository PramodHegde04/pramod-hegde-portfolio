# Pramod Hegde Portfolio

Static portfolio based on the supplied portfolio template, with Pramod Hegde's professional information and projects.

## Run locally

No build tools are required.

1. Extract the ZIP.
2. Open `index.html` in a browser.

For local development, VS Code Live Server can also be used.

## Files

- `index.html` — portfolio content
- `style.css` — layout and styling
- `script.js` — navigation, scroll state and contact form mailto behavior
- `Images/` — project visuals and photo placeholder
- `Pramod-Hegde-Resume.pdf` — resume

## Replace the photo later

Replace:

`Images/photo-placeholder.svg`

with the professional photo when ready, then update the image source in `index.html` if the filename changes.
